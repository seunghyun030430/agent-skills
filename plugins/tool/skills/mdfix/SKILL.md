# mdfix

마크다운 문서를 규칙에 맞게 고친다. 검사만 하고 끝내지 않는다. 파일을 직접 수정한 뒤 무엇을 왜 고쳤는지 짧게 보고한다.

규칙은 읽는 사람의 비용을 줄이려는 장치다. 한 줄 한 문장과 줄당 100자는 눈이 한 번에 한 사실만 따라가게 하고, 표는 항목 비교를 눈으로 가능하게 하고, 명사구 목록은 같은 정보를 더 적은 글자로 전한다. 규칙이 내용을 해치면 규칙을 꺾고 그 사실을 보고에 적는다.

## 대상 선택

인자 `$ARGUMENTS`가 있으면 그것이 대상이다. 파일 경로, 디렉터리, 글롭 모두 받는다. 디렉터리면 그 아래 `.md`를 재귀로 모은다.

인자가 없으면 변경분에서 찾는다.

```bash
{ git diff --name-only HEAD; git diff --name-only --cached; git ls-files --others --exclude-standard; } | sort -u | grep -E '\.md$'
```

- 결과가 비면 멈추고 사용자에게 알린다. 대상을 추측하지 않는다
- 제외: `CHANGELOG.md`, `LICENSE.md`, 머리말에 생성기 표시가 있는 자동 생성 파일, `node_modules`·`vendor`·`.git` 아래
- 사용자가 원본 보존을 원하면 사본을 만들어 사본을 고친다
- 대상이 5개를 넘으면 목록을 먼저 보여주고 진행 여부를 묻는다

## 작업 순서

각 단계는 완료 조건을 만족해야 다음으로 넘어간다. 검사 스크립트 경로는 `$CLAUDE_PLUGIN_ROOT/skills/mdfix/scripts/check.py`다.

1. **파악**: 대상 파일 전체를 읽는다. 문서의 목적, 독자, 기존 문체가 [합니다체](references/style-ko.md#문체)에서 얼마나 벗어났는지 확인한다.
   완료: 원문 문체(평서체 / 합니다체 / 해요체 / 혼재)를 한 줄로 기록함
2. **기계 검사**: `python3 -I "$CLAUDE_PLUGIN_ROOT/skills/mdfix/scripts/check.py" <파일>`을 실행한다.
   완료: 검사 결과 목록 확보
3. **표현 교정**: [references/style-ko.md](references/style-ko.md)를 읽고 AI slop, 구어·속어, 문체를 고친다.
   완료: 서술 문단 전부가 합니다체, 목록 항목·표 셀 전부가 명사구(인과 설명 항목은 합니다체 문장). 비유 은어는 정의된 용어까지 모두 교체함. 코드·식별자에 쓰여 바꿀 수 없는 것만 "용어 검토 권장"에 적음
4. **구조 교정**: [references/structure.md](references/structure.md)를 읽고 표 전환, 절차 문단의 번호 목록 전환, 중복 통합을 한다.
   완료: 검사 결과의 `라벨 불릿 묶음`·`속성 반복 목록`과 검사가 못 잡은 속성 반복 목록이 모두 표가 되었거나, 유지 사유를 보고에 적음
5. **문장·줄 길이**: structure.md의 [문장 단위 줄](references/structure.md#문장-단위-줄)과 [줄 길이 100자](references/structure.md#줄-길이-100자)를 적용한다.
   완료: 문장이 둘 이상인 서술 문단은 모두 목록이 되었거나 문장마다 하드 줄바꿈됨. 렌더링 기준 100자 초과 줄 0개, 또는 나눌 수 없는 줄을 보고에 적음
6. **포맷**: [references/markdown.md](references/markdown.md)를 기준으로 빈 줄, 줄바꿈, 이스케이프, 내보내기 흔적을 정리한다.
   완료: 블록 사이 빈 줄, 연속 빈 줄 없음, 문서 끝 개행 하나
7. **재검사**: 2단계 명령을 다시 실행한다.
   완료: 남은 항목은 모두 고쳤거나, 의도적으로 남긴 이유를 보고에 적음

모든 단계에 걸친 불변 조건:

- 코드블록 내용은 바꾸지 않는다. 예외는 다이어그램 라벨 문자열의 용어 교체뿐이며 구조는 그대로 둔다
- 숫자, 날짜, 이름, ID, 참조 번호, URL은 모두 보존한다. 지운 사실은 보고의 "빠진 내용"에 적는다
- 이미 규칙에 맞는 부분은 건드리지 않는다. 고칠 것이 없는 문서는 수정 없이 보고만 한다

## 규칙 요약

상세 기준과 예시는 각 참조 파일에 있다.

| 규칙 | 기준 | 상세 |
| --- | --- | --- |
| 서술 문단 문체 | 합니다체. 평서체·해요체는 모두 변경 | style-ko.md |
| 목록·표 셀 | 명사구, 마침표 없음. 인과 설명은 합니다체 문장 | style-ko.md |
| 구어·속어·이모지 | 비유 은어 포함, 목록 밖 단어도 기준으로 판단. 정의된 용어도 교체하고 다이어그램 라벨도 함께 맞춤 | style-ko.md |
| AI slop | 번역투, 공허한 수식어, 대조 구문, 요약 마무리, 문장 중간 굵게 삭제 | style-ko.md |
| 표 전환 | 속성 둘 이상 반복하는 목록 3개 이상. `**라벨**: 설명` 묶음 포함 | structure.md |
| 문장 단위 줄 | 독립 사실 3문장 이상은 목록, 이어지는 문단은 문장마다 공백 2칸 하드 줄바꿈 | structure.md |
| 줄 길이 | 렌더링 기준 한 줄 100자 이내. 링크는 보이는 글자만, 표는 셀마다. 문서 줄 수 제한 없음 | structure.md |
| 줄바꿈 | 문장 경계가 아닌 개행(에디터 폭 자국)은 합침 | markdown.md |
| 빈 줄 | 문단·목록·표·코드블록·헤딩 앞뒤 한 줄. 빈 줄에 공백 없음 | markdown.md |
| 내보내기 흔적 | 불필요 이스케이프, 빈 HTML 삭제 | markdown.md |

## 보고

수정이 끝나면 이 형식으로 출력한다. 파일 내용 전체를 다시 붙이지 않는다.

```
docs/setup.md (문체: 해요체 → 합니다체, 100자 초과 줄 12개 → 0개)

- AI slop 제거: "강력한 기능을 통해" 등 7곳
- 옵션 목록 6개 항목 → 표, 라벨 불릿 묶음 3개 → 표
- 설치 절차 서술 문단 → 번호 목록
- 구어체 3곳 교정 ("날렸습니다" → "삭제했습니다")
- 서술 문단 9개 → 문장 단위 줄바꿈, 독립 사실 나열 문단 2개 → 목록
- 중복 통합: 도입부 두 문단이 같은 목적 설명 → 한 문장

용어 교체: "태우기"(배치 태우기) → 배치 실행. 본문 4곳, mermaid 라벨 1곳

빠진 내용: 레거시 v1 설치 방법 문단. v2 전용 문서라 중복 판단.
```

- 100자를 넘긴 채 남긴 줄이 있으면 줄 번호와 이유를 적는다
- 규칙을 의도적으로 꺾었으면 이유를 한 줄로 적는다
- 여러 파일이면 파일별로 블록을 나눈다. 고칠 것이 없던 파일은 이름만 한 줄로 적는다
