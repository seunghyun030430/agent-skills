## CLAUDE.md 템플릿

```markdown
# CLAUDE.md

## 이 레포의 목적

"<주제>"를 직접 만들고 실행하며 체득하는 토이 프로젝트다. 문서 정리가 아니라
**돌아가는 코드와 관찰한 사실**이 산출물이다.

- 모드: <데모 | 가이드> — 가이드 모드에서는 사용자가 `TODO`를 채운다. Claude는 정답 코드를 먼저 쓰지 않고 힌트를 단계적으로 준다.
- 스택: <언어/프레임워크/도구와 버전>

## 마일스톤 규칙

- 마일스톤 하나 = 개념 하나 = 실행 가능한 상태 하나.
- 완료 기준(명령 + 기대 출력)을 통과해야 다음으로 넘어간다.
- 실행 진입점은 `make m<N>`.

## 노트 규칙 (`notes/`)

- 실제로 실행한 명령과 출력을 남긴다. 출력을 지어내지 않는다.
- 결론 → 명령 → 출력 → 해석 → 예상과 다른 점 순으로 쓴다.
- 확신이 없으면 "확인 필요"로 표기한다.

## 커밋 규칙

- 마일스톤 1개 = 커밋 1개. Conventional Commits + 한글 설명(`feat: M2 ...`).
- 관련 파일만 스테이징한다(`git add <파일>`).

## 작업 시 주의

- 합의한 마일스톤 밖으로 확장하지 않는다. 아이디어는 README "확장 아이디어"에 적는다.
- 레포 밖에 영향을 주는 명령(설치, 전역 설정, 원격 push, 비용 발생)은 실행 전에 확인받는다.
```

## Makefile 예시

```makefile
.PHONY: up m1 m2 m3 m4 clean

up:
	docker compose up -d --wait

m1: up
	<최소 구동 확인 명령>

m2: up
	<개념 1 실행 명령>

m4: up
	./scripts/break-it.sh

clean:
	docker compose down -v
```

## git 명령 메모

```bash
# 레포 루트가 현재 디렉토리인지 확인 (상위 레포의 하위면 결과가 cwd와 다름)
git rev-parse --show-toplevel 2>/dev/null

# 없으면 초기화 (기본 브랜치 main)
git init -b main

# 마일스톤 커밋 (관련 파일만)
git add src/consumer.py notes/02-rebalance.md README.md Makefile
git commit -m "feat: M2 consumer group 리밸런싱 구현"

# user 미설정 시 전역 설정을 바꾸지 않고 우회
git -c user.name="toy" -c user.email="toy@local" commit -m "..."

git log --oneline
```
