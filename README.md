# agent-skills

개인용 Claude Code 플러그인 마켓플레이스. **플러그인 = 분류**로 나누고, 스킬은 `/<분류>:<스킬>`로 호출한다.

## 설치

Claude Code 세션에서 아래를 순서대로 실행한다.

```
/plugin marketplace add <github-owner>/agent-skills
```

```
/plugin install study@agent-skills
```

분류(플러그인)별로 필요한 것만 설치한다. 설치 후 새 세션부터 스킬이 인식된다. 이미 추가한 마켓플레이스를 갱신하려면 `/plugin marketplace update`.

## 수록 스킬

### `study` — 기술 주제 학습

| 스킬 | 호출 | 설명 |
|---|---|---|
| `docs` | `/study:docs` | 기술 주제를 조사해 번호 매긴 Markdown 학습 문서 레포로 정리 |
| `toy` | `/study:toy` | 기술 주제를 직접 만들고 돌려 보며 체득하는 토이 프로젝트(마일스톤 + 깨뜨려 보기) |

## 사용 예제

### `/study:docs`

기술 주제 하나를 정리한 학습 문서 레포를 현재 디렉토리에 만든다.

- **빈 디렉토리에서 실행한다.** 산출물을 현재 작업 디렉토리에 생성하므로 새 디렉토리에서 시작한다.
- 문서 단위로 한글 커밋한다.
- 비교표 중심 README와 작성 컨벤션 CLAUDE.md를 세팅한다.
- 필요하면 사용자 확인을 받아 코드 샘플까지 작성하고, 산출물을 검증·보완한다.
- `/study:docs`로 명시적으로 호출해야 동작한다.

```
/study:docs kafka
```

### `/study:toy`

기술 주제 하나로 직접 만들어 보는 작은 프로젝트를 현재 디렉토리에 만든다. `docs`가 "문서로 이해하기"라면 `toy`는 "돌려 보며 체득하기"다.

- **빈 디렉토리에서 실행한다.**
- 학습 목표(핵심 개념 3~5개)와 스택을 정한 뒤, 개념 하나씩 다루는 **실행 가능한 마일스톤**으로 쪼갠다.
- 모드 선택: **데모**(Claude가 구현·실행·관찰) / **가이드**(사용자가 `TODO`를 채우고 Claude가 힌트·검증).
- **깨뜨려 보기**(가설 → 실험 → 관찰 → 해석 → 복구)를 필수 마일스톤으로 넣는다.
- 마일스톤마다 실제 실행 결과를 `notes/`에 남기고 커밋한다. 마지막에 처음부터 재현해 검증하고, 띄운 리소스를 정리한다.
- 설치·다운로드·전역 설정 변경·원격 push 같은 명령은 실행 전에 확인받는다.

```
/study:toy kafka
```
